# Object Detection Using Deep Learning

## 📌 Project Overview

This project focuses on object detection using deep learning techniques. 
The system identifies objects in images or video and draws bounding boxes 
around detected objects.

Object detection has applications in autonomous driving, surveillance, 
robotics, healthcare, and industrial automation.

## 🎯 Objectives

- Detect multiple objects in images and video.
- Identify the class of detected objects.
- Draw bounding boxes around detected objects.
- Achieve accurate and fast object detection.
- Provide a simple interface for testing the detection system.

## 🛠️ Technologies Used

- Python
- Deep Learning
- YOLO
- PyTorch
- OpenCV
- Streamlit
- NumPy
- Matplotlib

## 🧠 Methodology

The project follows these major stages:

1. Data Collection and Annotation
2. Image Preprocessing
3. Model Training
4. Model Evaluation
5. Object Detection and Inference
6. GUI Development

The project report describes a YOLOv5-based architecture for object detection,
including training, validation and real-time inference.

## 📊 Performance

According to the project report:

| Metric | Result |
|---|---:|
| mAP@0.5 | 93.2% |
| Precision | 91.7% |
| Recall | 89.5% |
